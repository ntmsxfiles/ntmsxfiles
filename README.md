## 🚀 Current tech stack

- **Core frontend**: JavaScript (ES6+), TypeScript, React (hooks, Context API), Next.js (App Router, API routes), SPA/SSR.
- **UI & styling**: styled-components, Material UI, responsive/adaptive layout, glassmorphism, complex modals (cart / checkout / account).
- **State & data**: React Context, localStorage, версионирование и миграции данных (DATA_VERSION), фильтрация и кеш‑инвалидация.
- **Backend & data layer**: Node.js, REST API на базе Next.js, Prisma ORM, проектирование моделей (users, products, orders, promocodes, reviews), seed‑скрипты.
- **Product & DX**: SEO (metadata, Open Graph, sitemap), оптимизация изображений (Next Image), работа с env‑переменными, Yandex Metrika, Git‑workflow, Prettier, Postman, работа с дизайном в Figma.

### 🧩 Production‑опыт (computer vision / quality control)

- **React + TypeScript, Redux Toolkit, React Router**: комплексные админ‑страницы (закрытые смены, виды капсул, настройки retention, очистка БД, управление пользователями).
- **Управление состоянием**: Redux Toolkit (слайсы, `createAsyncThunk`, селекторы), согласование типов `api/types.ts` с контрактами бэкенда, безопасная обработка ошибок API.
- **Работа с API**: интеграция с REST и WebSocket:
  - WebSocket‑подключение для онлайн‑контроля качества (живое обновление статистики и изображений, ретраи загрузки картинок, управление жизненным циклом сокета).
  - REST‑эндпоинты для статистики очистки БД, запуска очистки, retention‑настроек, CRUD для продуктов, капсул и пользователей.
- **Бизнес‑валидация и UX**:
  - Сложные формы: запрет дублирования сущностей, проверки диапазонов (количество, длина/ширина, лимиты), обязательные/опциональные поля.
  - Подтверждающие модалки и тосты успеха/ошибки для опасных операций (удаление смен, очистка БД, удаление капсул/продуктов).
  - Быстрая работа с фильтрами (плашки с крестиками, отдельный и глобальный «сброс»).
- **Безопасность и роли**:
  - Role‑based доступ (разделение функционала для админов и обычных пользователей: удаление смен, очистка БД, управление пользователями).
  - Разлогин после изменения собственных учётных данных (login/password): проверка `currentUser.id`, очистка токена и редирект на `/login`.
